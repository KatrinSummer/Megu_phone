# Резервная копия прогресса

Бесплатный воркер Cloudflare. Хранит копию прогресса, чтобы её нельзя было
потерять вместе с данными сайта на телефоне.

## Развернуть (один раз, минут пять)

1. Завести бесплатный аккаунт на dash.cloudflare.com.
2. В этой папке:

       npx wrangler login
       npx wrangler kv namespace create MEGU

   Команда напечатает `id = "..."` — вписать его в `wrangler.toml`.

3. Придумать ключ (любая длинная строка) и положить его в воркер:

       npx wrangler secret put MEGU_KEY

4. Выложить:

       npx wrangler deploy

   В конце напечатается адрес вида `https://megu-progress.<...>.workers.dev`.

5. В приложении на телефоне: меню → «Облако» → вписать этот адрес и тот же
   ключ → «Сохранить в облако сейчас».

## Дальше само

После каждой сессии прогресс уходит в облако через несколько секунд тишины.
На новом телефоне достаточно вписать адрес и ключ — история подтянется сама.

Копии по дням хранятся 120 дней:

    GET  ?days              какие дни есть
    GET  ?day=2026-09-07    прогресс на тот день
